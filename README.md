# 🎬 Live Movie Recommender & Auto-Updates Hub

A modern, responsive web application that automatically fetches live movie releases and offers smart story-theme-based recommendations for both Bollywood and Hollywood movies.

## ✨ Features

- **🆕 Live Dynamic Releases:** Auto-fetches latest movie releases directly from TMDB using real-time system date parameters.
- **🎯 Smart Search Algorithm:** Prioritizes exact matches, word boundary titles, and popularity rank to give accurate results.
- **📱 Responsive Layout:** Adjusts grid dynamic dimensions and auto-switches image resolutions (`w342` for mobile, `w500` for desktop).
- **⚡ Auto-Complete Suggestions:** Instant typing search recommendations.
- **🔍 Dual Industry Story Match:** Categorizes similar recommendations into distinct Bollywood and Hollywood sections.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **API:** [The Movie Database (TMDB) API](https://www.themoviedb.org/documentation/api)
